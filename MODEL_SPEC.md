# Atlas-1M Model Specification

## Mission

Atlas-1M is the first Atlas language model.

The objective is not intelligence.

The objective is to learn every component required to build a transformer model from scratch.

---

## Configuration

Vocabulary Size: 2048

Embedding Dimension: 64

Context Length: 64

Attention Heads: 2

Transformer Layers: 4

Feed Forward Dimension: 256

---

## Special Tokens

0 = <PAD>
1 = <UNK>
2 = <BOS>
3 = <EOS>

---

## Estimated Size

500K - 1M Parameters
