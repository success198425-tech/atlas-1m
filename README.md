# Atlas-1M

Engineering Memory • Reasoning • Legacy

Atlas-1M is the first experimental transformer model built entirely in Rust.

## Mission

Build a tiny transformer from scratch to understand every component required to create future Atlas models.

## Objectives

- Learn tokenization
- Learn embeddings
- Learn attention mechanisms
- Learn transformer architecture
- Learn model training
- Learn GGUF conversion

## Roadmap

- [ ] Tokenizer
- [ ] Embeddings
- [ ] Attention
- [ ] Transformer Block
- [ ] Training Loop
- [ ] Inference
- [ ] GGUF Export

## Long-Term Vision

Atlas-1M → Atlas-10M → Atlas-100M → Atlas Foundation

## Motto

Machines store data.

Atlas preserves experience.
